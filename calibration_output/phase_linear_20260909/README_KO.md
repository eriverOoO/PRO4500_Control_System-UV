# PRO4500 선형 위상 높이 보정 번들

이 번들은 2026-09-09에 촬영한 빈 스테이지와 2.95, 5.03, 7.96 mm 높이 블록으로 만든 임시 선형 보정입니다.

## 파일

- `phase_linear_20260909_2p95_5p03_7p96mm.npz`: Decoder의 `phase_linear` 높이 보정 파일
- `flat_stage_reference/reference_phase_0.npy`: 물리적 0도 빈 스테이지 기준 위상
- `flat_stage_reference/reference_phase_180.npy`: 물리적 180도 빈 스테이지 기준 위상
- `flat_stage_reference/reference_metadata.json`: GUI 기준면 저장 정보
- `phase_linear_calibration_report.json`: 입력 스캔, 방향 판정, 적합 결과와 한계
- `SHA256SUMS.json`: 핵심 파일 무결성 확인값

## 다른 PC에서 GUI로 사용하는 방법

1. ZIP 번들을 압축 해제한다.
2. 압축을 푼 `flat_stage_reference` 폴더를 아래 위치에 복사한다.

   `%LOCALAPPDATA%\PCB_FPP_Decoder\flat_stage_reference`

   대상 PC에 기존 기준면이 있다면 먼저 다른 이름으로 백업한다.
3. Decoder를 실행하고 높이 모드를 `phase_linear`로 선택한다.
4. 사인 위상 순서는 `swapped`를 사용한다.
5. 높이 보정 파일로 `phase_linear_20260909_2p95_5p03_7p96mm.npz`를 선택한다.
6. 2 mm 또는 6 mm 블록 스캔 폴더를 선택하고 계산한다.

대안으로 원본 `scan_20260909_164257`을 다른 PC에 복사한 다음 GUI 2단계에서 그 스캔의 `angle_000`을 빈 스테이지 0도로, `angle_180`을 빈 스테이지 180도로 등록해도 된다.

## 반드시 지킬 방향 조건

현재 Decoder는 ArUco ID로 스캔 시작 방향을 자동 교환하지 않는다. 따라서 측정 스캔의 `angle_000`이 반드시 물리적 0도여야 한다.

물리적 0도에서 카메라 영상의 마커 배치는 다음과 같다.

- ID 0: 오른쪽
- ID 1: 아래쪽
- ID 2: 왼쪽
- ID 3: 위쪽

한 번의 0/180 스캔이 끝나면 스테이지는 물리적 180도에 남는다. 다음 블록을 촬영하기 전에 X250으로 한 번 복귀시켜야 한다. 복귀하지 않으면 다음 스캔의 폴더 방향과 보정 방향이 뒤바뀐다.

## 보정값과 현재 성능

- 물리적 0도: `5.882308 rad/mm`, 높이 부호 `-1`
- 물리적 180도: `5.836248 rad/mm`, 높이 부호 `-1`
- 알려진 높이 내부 적합 최대 절대오차: 약 0.108 mm
- 별도 빈 스테이지 반복 촬영의 영점 차이: 0도 약 +0.141 mm, 180도 약 +0.076 mm
- 실제 Decoder 종단 확인: 5.03 mm 블록이 0도 5.049 mm, 180도 4.981 mm로 계산됨

## 판정 제한

이 보정은 중앙에 놓인 높이 블록으로 만들었다. 따라서 중앙 작업영역의 2.95~7.96 mm 범위에 대한 선형성은 확인됐지만, 스테이지 전 영역의 위치별 감도는 검증되지 않았다.

2 mm와 6 mm 블록은 보정에 사용하지 말고 독립 검증용으로 유지한다. 두 높이의 실제 측정 오차를 확인하기 전에는 생산 측정용 보정으로 확정하지 않는다.

카메라 위치, 프로젝터 위치, 초점, 패턴 크기, 노출 또는 기계 설치가 바뀌면 이 보정을 다시 사용하면 안 된다.
