# 독립 열 드리프트 촬영

이 프로그램은 기존 스캔·디코딩 흐름을 호출하거나 설정을 변경하지 않고,
카메라와 프로젝터의 냉간 시작 열 드리프트를 위한 최소 영상만 촬영합니다.

한 시점당 촬영은 다음 5장입니다.

- `White` 1장: 광량 변화와 고정 ArUco 마커의 픽셀 위치 확인
- `Sine 0/90/180/270°` 4장: wrapped phase와 modulation 확인

Gray code, inverse Gray code, 스테이지 회전은 사용하지 않습니다. 시점 사이에는
`Sine 0°` 패턴을 계속 표시하여 프로젝터의 열 부하가 끊기지 않게 합니다.

## 내일 실험 순서

1. 프로젝터와 카메라를 충분히 식힌 상태로 둡니다.
2. 빈 스테이지와 ArUco 마커가 보이게 하고, 장비를 고정합니다.
3. 카메라와 프로젝터를 켠 직후 `run_standalone_thermal_drift.bat`을 실행합니다.
4. 전원을 켠 후 바로 시작하면 `투사전원 ON 후 이미 지난 시간`을 `0`으로 둡니다.
   실행을 늦게 시작했다면 그 시간을 초 단위로 입력합니다.
5. 실내온도를 알면 입력하고 `열 드리프트 촬영 시작`을 누릅니다.
6. 90분 동안 스테이지, 카메라, 프로젝터를 건드리지 않습니다.

기본 일정은 시작 즉시와 처음 10분까지 1분 간격, 이후 90분까지 3분
간격입니다. 예정 시각과 실제 촬영 시각 차이도 자동 기록합니다.

## 저장 내용

`captures/thermal_drift/thermal_drift_YYYYMMDD_HHMMSS/`에 다음이 저장됩니다.

- `session_manifest.json`: 전원 ON 추정 시각, 투사 시작 시각, 카메라 설정, 일정,
  각 시점의 실제 시각과 요약
- `patterns/`: 실험에 실제 사용한 5개 패턴 복사본
- `thermal_drift_config.json`: 실험 시점의 전용 설정 복사본
- `timepoints/.../`: 각 시점의 5개 원본 PNG와 `timepoint.json`

프로젝터 온도는 측정하지 않고 `프로젝터 전원 ON 후 경과 시간`을 대리 지표로
저장합니다. 현재 카메라 제공자가 온도 API를 노출하지 않으므로 카메라 온도도
`null`로 명시적으로 기록합니다.

## 독립 설정

열 드리프트 전용 설정은 `thermal_drift_config.json`에 있습니다. 기존
`camera_config.json`을 읽거나 변경하지 않습니다. 기본 노출은 현재 메인 촬영과 같은
15,000 us / 0 dB이지만, 변경하더라도 메인 촬영 설정에는 영향을 주지 않습니다.

## 공유폴더 실시간 분석

촬영 PC의 저장 폴더에 UNC 공유 경로를 입력하면 분석 PC에서 원본을 읽을 수 있습니다.
분석 PC에서는 아래처럼 한 번씩 실행합니다. 반복 실행은 채팅의 감시 기능이 담당합니다.

```powershell
.\.venv-pc\Scripts\python.exe .\standalone_thermal_drift\analyze_live.py --share "\\LEELAB\5-9. Non-Planer\thermal drift"
```

공유폴더는 읽기만 하며 결과와 증분 캐시는 분석 PC의
`analysis_results/thermal_drift_live/<세션>/report.json`에 저장합니다.
5장과 `timepoint.json`이 완성된 시점만 분석합니다. 위상차 평면 피팅,
동일 ArUco 코너 정합 전/후 위상차, 마커 이동, 밝기 변화를 확인합니다.
ArUco 호모그래피는 평면상의 상대 변화를 줄이는 수단이며 드리프트의 원인을
특정 장비 하나로 확정하지는 못합니다.

종료 권고는 최근 15분 이상, 최소 6개 시점에서 아래 잠정 기준을 모두 만족할 때만 나옵니다.

- 위상차 평면 최대 변화 0.03 rad 이하, 공간 위상차 절댓값 p95 0.05 rad 이하
- 위상차 평면 잔차 RMS 0.05 rad 이하, 공통 유효 영역 70% 이상
- 동일 마커 2개 이상, 정합 재투영 RMS 0.5 px 이하, 마커 코너 이동 RMS 0.2 px 이하
- 동일 유효 영역의 White 밝기 변화 2% 이하

정합 전/후 위상 지표를 모두 확인합니다. 자료 누락, 설정 변경, 큰 시간 공백,
카메라 정합 불가, 신호 불량일 때는 종료를 권고하지 않습니다.
이는 위상/픽셀 단위의 잠정 안정 기준입니다. mm 정확도를 보증하려면 별도의
위상-높이 보정과 요구 허용오차가 필요합니다. 분석기는 촬영 장비를 자동 중지하지 않습니다.

### 마커 검출 잡음과 정합 영향 재분석

```powershell
.\.venv-pc\Scripts\python.exe .\standalone_thermal_drift\analyze_refined.py --session "\\LEELAB\5-9. Non-Planer\thermal drift\thermal_drift_20261006_161753" --max-index 30
```

저장된 White 원본에서 ArUco 코너를 서브픽셀로 재검출하고, RANSAC으로
제외한 코너와 정상 코너의 잔차를 따로 기록합니다. 최소 두 마커에서 각각
세 코너 이상, 전체 여섯 코너 이상을 요구합니다. 원근 정합과 이동·회전·배율
정합의 위상 결과를 비교하여 정합 모델에 민감한 결과도 드러냅니다.

원본과 기존 `report.json`을 변경하지 않고 같은 로컬 결과 폴더에
`refined_report.json`을 저장합니다. `--max-index`는 분석할 마지막 촬영
인덱스이며 시간(분/초)이 아닙니다. 초기 기준면 대비 변화, 최근 15분 변화,
시간 추세와 그 추세 주변의 산포를 기록합니다. 산포는 순수 잡음이 아니며,
모델 간 차이 역시 통계적인 신뢰구간이나 오차 상한은 아닙니다.
최근 시점과 두 정합 방식 모두에서 유효한 동일 픽셀 영역으로도 다시
비교하여 영역 선택의 영향을 확인하고, 공간 잔차와 시간 산포를 구분합니다.
이 분석은 위상 기준치를 완화하거나 자동 종료를 권고하지 않습니다.
카메라의 비선형 광학 변화와 프로젝터만의 열변화, mm 높이 오차를 완전히
분리·확정하려면 추가 기준 측정이 필요합니다.

### 공유폴더 없이 재분석할 소용량 특징 저장

`export_offline.py --session "<촬영 세션 경로>"`는 완료된 촬영만 읽고 로컬
결과 폴더의 `offline_features_YYYYMMDD_HHMMSS`에 특징을 저장합니다.
이미지와 전체 해상도 위상 맵은 저장하지 않습니다. 원시/두 종류 정합 위상의
희소 표본, 유효 여부, 표본 밝기/변조, 코너 좌표와 시간·설정, 기존 보고서를
남겨 공유폴더 없이 구간 비교와 위상차 평면을 다시 피팅할 수 있습니다.
`export_offline.py --verify "<로컬 특징 폴더>"`로 원본 접근 없이 검증합니다.
새 마커 검출, 저장하지 않은 영역 분석, 다른 방식의 정확한 재정합에는 원본이
필요합니다. 저장된 정합 표본은 최초 촬영 좌표계이며 직접 쌍별 정합과 다릅니다.
